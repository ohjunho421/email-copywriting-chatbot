⚠️ 중요: 반드시 SG.로 시작하는 SendGrid API 키를 입력하세요. SendGrid 무료 가입
📌 SendGrid API 키 생성 방법:
  1. SendGrid API Keys 페이지 접속
  2. "Create API Key" 클릭
  3. API Key Name: "PortOne Email Bot" 등 원하는 이름 입력
  4. 중요: "Full Access" 또는 "Restricted Access"에서 Mail Send 권한 ON
  5. 생성된 API 키 복사 (반드시 SG.로 시작)
  6. ⚠️ 발신자 인증 필수: Single Sender Verification에서 이메일 인증 완료
Twilio API 키 (SK.로 시작)는 사용할 수 없습니다!
💡 이메일 발송 방식:
  • Railway (배포 환경): SendGrid API 사용 (HTTP 방식)
  • 로컬 개발: Gmail SMTP 사용 (포트 465/587)
📌 Gmail 앱 비밀번호 생성 방법:
  1. Google 계정 보안 페이지 접속
  2. 2단계 인증 활성화
  3. "앱 비밀번호" 검색 후 생성
  4. 위 입력창에 16자리 비밀번호 입력
